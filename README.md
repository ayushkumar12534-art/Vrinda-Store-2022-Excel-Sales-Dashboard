# 📊 Vrinda Store 2022 – Excel Sales Dashboard

## 📌 Project Overview

The **Vrinda Store 2022 Sales Dashboard** is an interactive **Microsoft Excel dashboard** created to analyze sales and order data.

The dashboard provides insights into sales performance, customer demographics, order channels, top-performing states, categories, and order status.

---

## 🎯 Objectives

- Analyze sales and order performance
- Compare sales between Men and Women
- Analyze orders by Age and Gender
- Identify Top 5 States by Sales
- Analyze orders by different sales channels
- Track order status
- Create an interactive dashboard using Excel

---

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Design

---

## 📊 Dashboard Features

### 1. Orders vs Sales

Shows the relationship between:

- Sales Amount
- Number of Orders

### 2. Sales: Men vs Women

A pie chart showing the sales contribution of:

- Men
- Women

### 3. Orders: Age vs Gender

Analyzes orders across different age groups:

- Adult
- Senior
- Teenager

and compares Male and Female customers.

### 4. Top 5 States by Sales

Displays the top-performing states based on sales amount.

### 5. Orders by Channel

Analyzes orders from different sales channels:

- Amazon
- Flipkart
- Myntra
- Meesho
- Nalli
- Ajio
- Others

### 6. Order Status

Shows the distribution of different order statuses, including:

- Delivered
- Cancelled
- Other statuses

### 7. Interactive Filters

The dashboard contains interactive slicers for:

- Month
- Category
- Channel

Users can select different values to dynamically analyze the dashboard.
